همه‌جو HameJoo

HameJoo همه‌جو

جستجوی سریع آگهی و کسب‌وکار ایران، مستقیم از داخل کروم. نتیجه همیشه روی hamejoo.ir باز می‌شود. Search Iranian classifieds and businesses straight from Chrome. Results always open on hamejoo.ir.

ویژگی‌ها Features

جستجو از خود مرورگر شروع می‌شود. صفحهٔ نتیجه روی دامنهٔ رسمی باز می‌شود، نه داخل افزونه. Search starts in the browser. The results page opens on the official domain, not inside the extension.

پاپ‌آپ نوار ابزار Toolbar popup

روی آیکن کلیک کنید، عبارت را بنویسید و Enter بزنید. آخرین عبارت فقط روی همین دستگاه، در حافظهٔ محلی مرورگر، برای دفعهٔ بعد پر می‌شود. سقف عبارت ۲۰۰ نویسه است. Click the icon, type a query, and press Enter. The last query is filled in next time from browser storage on this device only. Queries are limited to 200 characters.

نوار آدرس با hj Address bar with hj

در نوار آدرس hj را بنویسید، فاصله بزنید و عبارت را وارد کنید. پیشنهاد نمایش‌داده‌شده «جستجو در همه‌جو» است. Type hj in the address bar, press space, then the query. The suggestion reads «جستجو در همه‌جو».

منوی راست‌کلیک Right-click menu

متن را انتخاب کنید و «جستجو در همه‌جو» را بزنید. از منوی صفحه، یا از منوی خود آیکن افزونه، مورد «باز کردن همه‌جو» صفحهٔ اصلی را باز می‌کند. Select text and choose «جستجو در همه‌جو». From the page menu, or the extension icon’s menu, «باز کردن همه‌جو» opens the homepage.

میانبر Alt+H Alt+H shortcut

میانبر پیشنهادی Alt+H پاپ‌آپ را باز می‌کند؛ در ویندوز، لینوکس و macOS همین ترکیب در مانیفست ثبت شده است. اگر میانبر دیگری گرفته باشد، از تنظیمات کروم قابل تغییر است. The suggested shortcut Alt+H opens the popup. The manifest sets that combination on Windows, Linux, and macOS. Chrome lets you change it if the keys are already taken.

روش کار How it works

مخزن اسکرین‌شات ندارد. پیش‌نمایش‌های زیر با CSS از روی رابط واقعی ساخته شده‌اند. خود افزونه فارسی است. The repository has no screenshots. These previews are CSS reconstructions of the real interface. The extension itself is in Persian.

۱1 نصب Install

از فروشگاه کروم نصب کنید. برای توسعه، مخزن را کلون کنید و در chrome://extensions با روشن بودن Developer mode، Load unpacked را روی پوشهٔ پروژه بزنید. کروم و مرورگرهای سازگار با Chromium. Install from the Chrome Web Store. To develop, clone the repo and use Load unpacked on chrome://extensions with Developer mode on. Chrome and other Chromium browsers.

۲2 جستجو Search

پاپ‌آپ، میانبر، کلیدواژهٔ hj، یا راست‌کلیک روی متن انتخاب‌شده. نمونهٔ داخل پاپ‌آپ: آیفون ۱۳، پژو ۲۰۶، اجاره تهران. Use the popup, the shortcut, the hj keyword, or a right-click on selected text. The popup’s own examples are iPhone 13, Peugeot 206, and rent in Tehran.

۳3 نتیجه Results

پاپ‌آپ و منوی راست‌کلیک نتیجه را در زبانهٔ تازه باز می‌کنند. نوار آدرس، بسته به نحوهٔ تأیید پیشنهاد، زبانهٔ فعلی یا زبانهٔ تازه را به‌روز می‌کند. The popup and the right-click menu open the result in a new tab. The address bar updates the current tab or opens a new one, depending on how the suggestion is accepted.

نشانی نتایج Results URL https://hamejoo.ir/search?q=…

اگر عبارتی نباشد، افزونه صفحهٔ اصلی hamejoo.ir را باز می‌کند؛ از جمله با مورد «باز کردن همه‌جو». پاپ‌آپ با فیلد خالی فقط همان فیلد را دوباره فعال می‌کند و جایی نمی‌رود. With no query, the extension opens the hamejoo.ir homepage, including via «باز کردن همه‌جو». An empty popup only refocuses the field and does not navigate.

حریم خصوصی و مجوزها Privacy and permissions

افزونه رمز، توکن یا کلید API ندارد و محتوای تب‌های دیگر را نمی‌خواند. The extension has no password, token, or API key, and it does not read the contents of other tabs.

در مانیفست اسکریپت محتوا تعریف نشده است. روی صفحه‌هایی که باز می‌کنید کدی تزریق نمی‌شود، ردیاب شخص‌ثالثی در افزونه نیست، و کد راه‌دور اجرا نمی‌شود. جستجو فقط با باز شدن یک نشانی روی hamejoo.ir انجام می‌شود. The manifest declares no content script. Nothing is injected into pages you visit, the extension has no third-party tracker, and it runs no remote code. A search happens by opening a URL on hamejoo.ir.

سیاست حریم خصوصی محصول: Product privacy policy: hamejoo.ir/privacy

  • مجوز Permission

    contextMenus

    ساخت دو مورد راست‌کلیک: جستجوی متنی که انتخاب کرده‌اید، و باز کردن همه‌جو از منوی صفحه یا آیکن افزونه. Adds two right-click items: search the text you selected, and open HameJoo from the page menu or the extension icon.

  • مجوز Permission

    storage

    آخرین عبارت پاپ‌آپ با کلید lastQuery در chrome.storage.local روی دستگاه شما می‌ماند. افزونه این مقدار را به سرویس دیگری نمی‌فرستد. خود جستجو، با باز شدن نشانی نتایج، به hamejoo.ir می‌رود. The popup’s last query is kept under the key lastQuery in chrome.storage.local on your device. The extension does not send that saved value to another service. The search itself goes to hamejoo.ir by opening the results URL.

  • مجوز میزبان Host permission

    https://hamejoo.ir/*

    تنها میزبان مجاز، سایت رسمی است. افزونه به سایت دیگری دسترسی میزبانی ندارد. کاری که با این دامنه می‌کند باز کردن صفحهٔ اصلی و صفحهٔ نتایج است. The only allowed host is the official site. The extension has no host access to any other site. What it does with this domain is open the homepage and the results page.
